# 个人版本需求台账

本文记录已经由项目所有者确认、需要长期保留的个人版本行为。它是上游同步、回归检查和真机验收的稳定清单，不以某次提交或目录结构为边界。

状态含义：

- **已实现待验收**：当前分支已有实现，但仍需要相应自动检查或真机证据。
- **已实现待真机**：当前代码和云端 Release archive 已通过，仍需相应真机行为证据。
- **回归修复待复验**：真机已发现回归并完成针对性代码修复，仍需复验原始复现步骤。
- **未通过待调整**：真机结果不符合验收标准，调整方案尚未完成。
- **规划**：产品方向已确认，但尚未进入当前实现范围。

## 文字和电子书阅读器

|---|---|---|---|
| RDR-001 | 继续使用上游原生 EPUB 文字/图片章节阅读，不恢复独立 Readium 书库。 | 已实现待验收 | 文字章节进入文字阅读器，纯图片 spine 可进入图片阅读器，不建立第二套书库。 |
| RDR-002 | 文字内容支持分页和连续滚动两种阅读模式。 | 已实现待验收 | 用户可以切换模式，重新进入书籍后偏好和阅读位置可恢复。 |
| RDR-003 | 分页文字模式常驻显示章节、时间、电量和当前页/总页数；滚动文字模式不常驻显示。 | 已验收 | 隐藏导航栏和工具栏后信息仍可见；显隐栏、旋转和翻页时正文不跳动。 |
| RDR-004 | 阅读器右上角使用通用“阅读设置”图标，而不是只表示字号的“大小”图标。 | 已验收 | 漫画和文字共用设置入口图标，设置内容仍按当前阅读器类型区分。 |

| RDR-007 | 既有水平填充与 iPad 双页外侧安全区逻辑保持独立；左、右边距作为默认 `0` 的额外每页文字边距，分页和滚动共用。 | 已实现待验收 | 默认值保持第一里程碑视觉不变；修改任一侧只增加对应侧文字边距，双页安全区仍只出现在整组书页外侧。 |
| RDR-008 | 文字阅读器支持系统文字选择；当前验收只要求长按选择，不新增应用层双击选词手势。 | 回归修复待复验 | 分页和滚动均可长按、拖动选区和调用系统菜单；选择过程不触发翻页或破坏工具栏手势，翻到新页后的第一次点击也必须立即执行原 tap zone 动作。 |
| RDR-009 | 分页、单双页、旋转、显隐工具栏和模式切换不能造成正文偏移、跳页或进度损坏。 | 已验收 | iPhone 竖/横屏和 iPad 单/双页集中验证当前位置与视觉稳定性。 |

## 上游同步使用方法

每次检查官方更新时，按本台账逐项给出以下结论之一：

1. 上游没有触及该需求。
2. 上游已经提供完整等价行为，可以删除个人维护代码。
3. 上游提供了部分能力，需要保留最小个人差异。
4. 上游行为与个人需求冲突，需要用户选择后才能合入。

不能仅根据文件仍能编译、类或方法仍存在，就把需求标记为已通过。
